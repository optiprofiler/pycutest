The distribution does not include source code, compiled libraries, or problem
files from PyCUTEst, CUTEst, or MASTSIF. They are installed or configured
separately when the adapter is used:

- [PyCUTEst](https://github.com/jfowkes/pycutest) is an optional runtime
  dependency licensed under GPL-3.0-or-later.
- [CUTEst](https://github.com/ralna/CUTEst) is an external runtime dependency
  distributed under its own upstream license.
- [MASTSIF](https://bitbucket.org/optrove/sif/src/master/) contains separately
  obtained problem definitions. Users must follow its upstream provenance,
  citation, and licensing information.

`probinfo_pycutest.csv` is generated by querying the configured problem
collection through this adapter. It is included for selection and does not
contain PyCUTEst, CUTEst, or MASTSIF source code.
